1. Visão Geral e Arquitetura da Solução

A Empório da Música (Campo Grande/MS) necessita de um agente capaz de lidar com dois tipos distintos de informação: (1) Dados operacionais estruturados (data/*.csv) — produtos, estoque, preços, promoções e pedidos — que exigem precisão numérica absoluta sem alucinação; e (2) Diretrizes normativas (data/políticas_da_loja.pdf) — regras de troca/devolução, prazos, garantia, frete, horários e escopo de atendimento.

Para atender ambos os cenários com rigor de produção, projetamos uma Arquitetura Híbrida baseada em Function Calling (ReAct) + Banco Relacional SQLite Higienizado + RAG Tri-Modal com Reciprocal Rank Fusion (RRF):

2. Justificativa das Decisões Técnicas

Decisão Escolha Adotada Justificativa Técnica
Abordagem / Framework Híbrida: Function Calling (ReAct) + SQL Relacional + Policy RAG Consultas sobre catálogo e pedidos exigem filtros numéricos exatos (preco <= 1000, stock > 0, is_active == 1) e joins relacionais, onde um RAG puramente vetorial alucinaria valores. Já o manual em PDF é recuperado via RAG estruturado por seções.
Retrieval sobre Políticas (PDF) Chunking por Seção + Tri-Modal (TF-IDF + Char N-Grams + LSA/SVD Dense) + RRF O manual de 8 páginas é segmentado nas 10 seções numeradas reais do documento (preservando tabelas de frete e parcelamento inteiras). O ranking combina similaridade lexical, n-gramas de caracteres (tolerante a erros de digitação) e vetores semânticos densos via Reciprocal Rank Fusion (RRF).
Regras de Negócio e Cálculos 8 Tools Determinísticas em Python Cálculos críticos — desconto PIX de 5% não cumulativo com promoções ativas (Seção 6.2), parcelamento escalonado (mín. R$ 50 até 3x; R$ 80 de 4–6x; R$ 100 de 7–12x — Seção 3.1) e contagem de dias corridos para Direito de Arrependimento (7 dias) e Garantia (30/90 dias) — são executados em Python e entregues prontos ao LLM.
Modelo e Provedor Agnóstico (Gemini, OpenAI, Groq, Ollama) + Motor ReAct Local Suporta Function Calling nativo via API (gemini-2.5-flash, gpt-4o-mini, llama-3.3-70b) e inclui um motor ReAct determinístico local (LLM_PROVIDER=auto) que permite testar todo o projeto imediatamente após o git clone mesmo sem chaves externas.
Persistência de Histórico SQLite (data/chat_history.db) Armazena sessões, mensagens e o trace JSON de todas as ferramentas invocadas em cada turno, permitindo retomada de contexto e resolução de correferências multi-turno.

3. Tratamento de Dados, Anomalias Detectadas e Suposições

Durante a auditoria dos arquivos data/*.csv e data/políticas_da_loja.pdf, identificamos e tratamos automaticamente no código (src/database.py e src/policy_rag.py) os seguintes casos de borda:

  • Produto Ativo com Estoque Zero (out_of_stock): O violão Giannini GF-3D Dreadnought Sunburst (product_id=96) possui status='active' mas stock_quantity=0. Seguindo a Seção 7.3, ele nunca é ofertado como disponível e a tool sugere automaticamente 3 violões equivalentes em estoque.
  • Produto Descontinuado com Estoque Residual (discontinued): O baixo Ibanez Bass 2X (product_id=136) possui stock_quantity=13 mas status='discontinued' (assim como o violão 7 cordas Shelby SN-7C, ID 113). O status discontinued prevalece e o agente recomenda modelos equivalentes ativos.
  • Promoções Ativas vs. Expiradas e Regra do PIX: Das 25 promoções em promotions.csv, apenas 4 estão ativas (is_active=1): Kalani KAL-700T (-10%), Ohana CK-20 (-20%), Crafter HT-100 (-18%) e Taylor 110e (-8%). As outras 21 (incluindo Takamine GD20 com 12%) estão expiradas (is_active=0). O agente informa com transparência quando uma campanha encerrou (Seção 7.3) e bloqueia cumulatividade do PIX (5%) em itens já promocionais (Seção 6.2).
  • Divergência Nome vs. Descrição (IDs 135–144) e Categorias Vazias (IDs 6, 7, 8): Itens sintéticos onde a descrição cita marca diferente do título recebem flag de anomalia priorizando o name canônico. As categorias Sopro (Madeiras/Metais) e Cordas Orquestrais (sem itens em products.csv) retornam aviso transparente de ausência de estoque cadastrado.
  • Reconciliação de Ambiguidades do PDF: (a) A Seção 1.2 lista o telefone/WhatsApp (67) 3341-4444 e a Seção 7 lista (67) 3321-4500; o agente apresenta ambos distinguindo loja física e central WhatsApp. (b) A Tabela 3 resume parcela mínima de R$ 100, enquanto a Seção 3.1 detalha o escalonamento R$ 50 (1–3x), R$ 80 (4–6x) e R$ 100 (7–12x), adotado na calculadora.

4. Evoluções Implementadas com Sucesso (Além do Escopo Base)

🔒 1. Verificação em 2 Fatores (2FA) e Mascaramento LGPD

Em conformidade com a Seção 9 (LGPD), buscas de pedido apenas por número (ex.: #7) mascaram e-mail e telefone (le***a@jmail.com, (67) *****-0123). Ao confirmar titularidade (nome, e-mail ou telefone), o status muda para verificado_2_fatores.

🚚 2. Motor Tarifário de Frete por Peso e Cubagem

Estimativa automática de peso/dimensões por categoria (Ukulele 1,2 kg; Violão 3,2 kg; Guitarra 4,8 kg; Bateria 28 kg) + cálculo de frete regional (Interior MS vs. Outros Estados) + seguro ad valorem (1,5%) para PAC, Jadlog e SEDEX.

🎫 3. Logística Reversa e Chamados SAC (Write Tools)

Tools transacionais registrar_solicitacao_troca_devolucao (gera protocolo TROCA-2026-XXXX e código de postagem reversa gratuita LOG-REV-BR...) e abrir_chamado_reclamacao (protocolo SAC-2026-XXXX com SLA de 24h úteis — Seção 7.3).

🧠 4. RAG Denso (LSA/SVD) + Reciprocal Rank Fusion

O PolicyRAG combina 3 sinais (TF-IDF de palavras com sublinear TF, Char N-Grams 3..5 e Embeddings Semânticos Densos via TruncatedSVD L2-normalizado) fundidos via Reciprocal Rank Fusion (RRF).
